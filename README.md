# PaviScan

Buracos em pavimento a partir de ortofotos: área, opções de reparo, orçamento e antes/depois.

Comece por `PLAN.md`. Para desenvolver com o Claude Code:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
git init -b main && git add -A && git commit -m "Scaffold inicial"
claude          # depois: /marco M1
```

Estado atual em `PROGRESS.md`. Os preços em `config/precos.csv` são placeholders.
